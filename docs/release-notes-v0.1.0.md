# NOVA v0.1.0 — First public release / 首个公开版本

NOVA is a calm, keyboard-first Chromium new tab for AI, search, URLs, calculations, and everyday destinations.

NOVA 是一款安静、键盘优先的 Chromium 新标签页，把 AI、搜索、网址、计算器与常用网站收进同一个入口。

## Highlights / 亮点

- One universal command bar with contextual suggestions / 单一智能输入框与场景化建议
- Six AI providers and eleven search destinations / 6 个 AI 平台与 11 个搜索目标
- Editable, draggable quick links with TradeFlow and Alibaba Seller defaults / 可编辑、拖拽的快捷方式，默认包含 TradeFlow 与阿里巴巴卖家后台
- Command palette, Focus Mode, light/dark/system themes, five accents / 命令面板、专注模式、浅色/深色/跟随系统主题及 5 种强调色
- Local-only preferences and destination metadata; prompts are never stored / 设置与访问目标仅保存在本机，不保存提示词
- Manifest V3 with only the `storage` permission / Manifest V3，仅申请 `storage` 权限

## Install / 安装

1. Download `nova-ai-new-tab-v0.1.0.zip` below / 下载下方 ZIP。
2. Unzip it / 解压文件。
3. Open `chrome://extensions` and enable Developer mode / 打开扩展程序页面并开启开发者模式。
4. Choose Load unpacked and select the unzipped folder / 点击“加载已解压的扩展程序”并选择解压目录。
