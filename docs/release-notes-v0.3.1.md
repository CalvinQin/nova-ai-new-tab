# NOVA v0.3.1 — Store listing correction / 商店文案整改

NOVA v0.3.1 updates Chrome Web Store-facing metadata following a `Yellow Argon` keyword-spam rejection. The package and listing now describe one clear, keyboard-first new-tab purpose and no longer contain long lists of third-party brands or sites.

NOVA v0.3.1 针对 `Yellow Argon` 关键词堆砌拒绝整改 Chrome 应用商店相关元数据。包内和商店文案现在只清晰说明键盘优先的新标签页用途，不再包含第三方品牌或网站长列表。

## Install / 安装

1. Download `nova-ai-new-tab-v0.3.1.zip` below / 下载下方 ZIP。
2. Unzip it / 解压。
3. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder / 打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，并选中解压后的目录。
