# NOVA v0.1.2 — China-ready routing / 中国区路由增强

NOVA v0.1.2 adds an in-product English/Simplified Chinese switch, China AI destinations, Baidu search, and saved drag ordering for all AI and search choices.

NOVA v0.1.2 新增插件内英语／简体中文切换、中国区 AI、百度搜索，以及 AI 和搜索引擎的拖拽排序与本地保存。

## Highlights / 亮点

- English and Simplified Chinese switch with inline SVG flags / 内联 SVG 国旗的中英文切换
- 豆包、Kimi、通义千问、腾讯元宝 / four China AI destinations
- 百度 and `/baidu` / 百度搜索与 `/baidu` 斜杠命令
- Drag AI providers and search engines in Settings; picker follows the same order / 设置中拖拽排序，命令栏选择器同步生效
- No new permissions, backend, analytics, remote code, or prompt history / 不增加权限、后端、统计、远程代码或提示词历史

## Install / 安装

1. Download `nova-ai-new-tab-v0.1.2.zip` below / 下载下方 ZIP。
2. Unzip it / 解压文件。
3. Open `chrome://extensions` and enable Developer mode / 打开扩展程序页面并开启开发者模式。
4. Choose Load unpacked and select the unzipped folder / 点击“加载已解压的扩展程序”并选择解压目录。
