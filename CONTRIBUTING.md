# Contributing / 参与贡献

## English

Thanks for helping improve NOVA. Please keep changes focused and explain the user-facing behavior they affect.

1. Fork the repository and create a short-lived branch.
2. Install dependencies with `npm ci`.
3. Make the smallest coherent change.
4. Run `npm run check`.
5. Include screenshots for visible UI changes and tests for behavior changes.
6. Open a pull request describing the problem, solution, and verification.

Please do not add analytics, remote code, broad permissions, prompt history, or API credentials without an explicit design discussion.

## 简体中文

感谢你帮助改进 NOVA。请保持改动聚焦，并说明会影响哪些用户行为。

1. Fork 仓库并创建短期分支。
2. 使用 `npm ci` 安装依赖。
3. 完成范围最小且逻辑完整的改动。
4. 运行 `npm run check`。
5. 可见界面改动请附截图，行为改动请补测试。
6. 创建 Pull Request，说明问题、解决方案与验证结果。

未经明确设计讨论，请勿引入统计分析、远程代码、宽泛权限、提示词历史或 API 凭证。
